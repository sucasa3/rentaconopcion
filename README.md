# SuCasa Home Hub

Build the SuCasa MVP (mobile-first web app)

Product Vision

SuCasa is the trusted operating system for homeownership. We help homeowners manage, protect, improve, and grow the value of their home while connecting them with trusted local professionals.

This is not a contractor directory or a lead-generation site. The homeowner is the primary user, and service professionals fund homeowner acquisition through a monthly membership.

Design Style

Design should feel like Apple + Airbnb + Stripe:

Clean and premium

Mobile-first

Modern with soft gradients and rounded cards

Fast and intuitive

Trustworthy and simple

Light mode first with dark mode support

Primary colors:

Deep blue for trust

Green for growth and home value

Plenty of white space

Key MVP Rule

Every action should support this core loop:
Homeowner requests help -> SuCasa matches homeowner with a trusted professional -> Professional claims the opportunity -> Homeowner becomes a long-term SuCasa member.

Use realistic placeholder data and make every screen navigable so it feels like a working product prototype.
