# Publish homeowner detail and refine Agent Today

## Outcome
- Publish the already-approved Agent and Lender **View homeowner** redesign to `sucasa.com` first.
- Refine **Agent Today** in preview as a fast daily-priority workflow.
- Keep Today intentionally lighter than View homeowner: **priority + reason + opener + action**, with deeper evidence staying in the detail view.
- Do not publish the Agent Today refinement until it is reviewed and approved.

## Agent Today changes
1. **Compact Daily Intelligence**
   - Preserve the greeting and “Your relationships are moving.”
   - Replace the paragraph-plus-bullets treatment with a short briefing and compact inline totals for attention, follow-ups, and monitored homeowners.
   - Keep handled-today confirmation, but reduce the section’s height so Start here enters the first mobile viewport or sits immediately below it.

2. **Remove the redundant explainer**
   - Remove the full “SuCasa found someone worth your attention” card from the main flow.
   - Preserve first-run acknowledgement without inserting another large block before Start here.

3. **Make Start here dominant**
   - Restyle the first relationship as the page’s primary white/warm card with one restrained orange accent.
   - Present identity and canonical opportunity first, followed by up to three non-duplicative supporting facts when supplied by the existing queue.
   - Keep the existing canonical temperature label subtle; never invent or upgrade priority.

4. **Simplify the action story**
   - Collapse the current segmented content into: **Why now**, **Recommended next step**, and a compact **Suggested opener** intelligence surface.
   - Continue using only the queue’s existing canonical reason, narrative, facts, and opener. No new conclusions or agent/lender crossover copy.
   - Retain Copy only if the existing opener interaction supports it cleanly; otherwise preserve the opener without adding new behavior.

5. **Make outreach immediate**
   - Keep the existing server-authoritative channel list and recommended-channel styling.
   - Show the recommended available channel as the navy primary action, other permitted channels as secondary, and View homeowner as the deeper-research action.
   - Preserve blocked-channel explanations and current automatic outreach tracking.

6. **Compact outcome logging**
   - Replace six always-visible outcome controls with one compact “Log outcome” disclosure.
   - Reveal the same six existing agent outcomes and submit through the unchanged outcome function; preserve queue advancement, acknowledgements, and refresh behavior.

7. **Turn Next relationships into a queue**
   - Make secondary rows substantially denser: rank/priority, homeowner, concise canonical opportunity/reason, strongest available supporting line, recommended permitted channel, and View homeowner.
   - Do not repeat the full Why Now, opener, or evidence architecture for every row.

8. **Match the approved detail system**
   - Reuse the approved SuCasa typography, spacing, corner treatment, neutral page/cards, warm relationship surface, deep navy actions, restrained orange, and intelligence-blue guidance.
   - Scope any Today-specific presentation tokens/classes so other workspaces and public pages remain unchanged.

## Behavior preserved
- No changes to ranking, opportunity generation, canonical reasons, opener generation, permissions, channel eligibility, navigation, outcome values, tracking, or backend behavior.
- Empty, preparing, quiet-day, handled-today, search, metrics, tasks, and opportunity links remain functional.
- No lender language or unsupported property conclusions are introduced.
