# SuCasa homepage: one home, connected action

Redesign only the public homepage into a concise, premium introduction to SuCasa. The draft will remain in preview until final approval; the published site and custom domain will not be updated.

## First five seconds

- Lead with the exact message: **“Your home is always changing.”** followed by **“SuCasa tells you what matters — and what to do next.”**
- Keep the supporting copy short and focused on home changes becoming useful action for homeowners, agents, and lenders.
- Use **Start free** as the primary homeowner onboarding path and **See how it works** as an in-page jump to the three-step explanation.
- Preserve sign-in, language selection, navigation, authentication, and existing destination routes.

## Connected product showcase

Build the main visual as one coordinated SuCasa ecosystem rather than three separate screenshots:

- Center: a dominant Home Profile view based on the real homeowner screen, with the property photo, value, equity, Home Score, and care context presented as a clearly labeled fictional demonstration.
- Left: a smaller Agent Today view based on the real “who / why now / what to say / what next” experience.
- Right: a smaller Lender Today view based on the real daily intelligence experience, using compliant, factual language and fictional demonstration data.
- Connect the views through shared visual alignment, restrained signal chips, subtle depth, and gentle motion. Chips may include “Value updated,” “Annual review due,” “Maintenance due,” “Client to call today,” and “Opportunity found.”
- No real account data, unsupported intent claims, stock photography, or invented product capabilities. Motion will respect reduced-motion preferences.

## Short page structure

1. **Hero** — unified message, two actions, and the connected three-screen product showcase.
2. **One home. Three kinds of value.** — three compact audience cards using the supplied homeowner, agent, and lender messages.
3. **How SuCasa works** — watches the home, surfaces what matters, helps take the next step.
4. **Product proof** — three polished excerpts based on Home Profile, Agent Today, and Lender Today, each with one plain-English caption.
5. **Choose your SuCasa experience** — routes homeowners to onboarding, agents to `/agents`, and lenders to `/lenders`.
6. **Final action** — “Stop guessing. Start knowing what matters.” with **Start free**.

Remove the current long sequence of services, professional-network promotion, sample financial tiles, testimonials, and repeated calls to action from the homepage only. Their existing routes and application functionality remain unchanged.

## Visual system

- Warm white and neutral surfaces, deep navy structure, and restrained SuCasa orange `#DA5431` through the existing semantic color system.
- Apple-like hierarchy: large clear typography, generous space, few elements, crisp product surfaces, and understated shadows.
- Avoid cold SaaS gradients, decorative clutter, giant feature grids, nested cards, and presentation-style density.
- Build mobile first: the homeowner screen leads, with agent and lender views arranged as connected supporting moments rather than unreadably scaled desktop panels.
- Keep English and Spanish complete using the existing language system; update homepage metadata to match the new positioning.

## Boundaries

- Frontend and homepage copy only; no database, permissions, billing, consent, Home Team, campaign, onboarding, or product-logic changes.
- Existing Agent Today, Lender Today, and homeowner screens remain authoritative references; the public showcase will be a safe fictional recreation, not an authenticated data fetch.
- Do not publish or change the live SuCasa domain during this work.

## Approval and verification

- Check phone and desktop layouts, text fit, keyboard focus, contrast, reduced motion, navigation, language switching, and both calls to action.
- Confirm there is no horizontal overflow, missing translation text, console error, or accidental exposure of account data.
- Run the existing test suite and type checks.
- Deliver the finished draft at the project preview URL for review. Only publish after separate final approval.
