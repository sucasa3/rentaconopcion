# src/lib rules
- Multi-property CSV import (household-import.ts planner + import_household_batch RPC) is applied (migration 0042) and gated by HOUSEHOLD_IMPORT_ENABLED; capacity is checked under one org-level transaction lock, uploads only into the actor's own book, and enrichment holds live in the database (queue guard + enrichment_intake_holds), so flag off never releases lookups — release is explicit and visibility-checked; rollback never purges.
- Mixed-list upload (upload-intake.ts planner + mixed-upload.server.ts + stage_mixed_upload/approve_upload_spend RPCs) is off unless the actor's user id is in the MIXED_UPLOAD_USER_IDS secret; its schema lives unapplied in docs/release-candidates/mixed-upload-migration.sql. Every added home is held until batch approval; saved-record homes get a zero-dispatch grant and paid homes a grant capped at the approved count, with the dollar ceiling re-checked in the RPC — the upload itself never queues a paid lookup and reuse can never spend.
